Plugins Store V3 — тема WordPress
=================================

Установка
1. В WordPress откройте «Внешний вид → Темы → Добавить новую → Загрузить тему».
2. Загрузите plugins-store-v3.zip и активируйте тему. Главная и ссылки работают сразу.
3. Для постоянных адресов откройте «Внешний вид → Страницы Plugins-store» и
   создайте недостающие страницы. Для обычных красивых URL настройте постоянные
   ссылки WordPress. Тема не меняет содержимое существующих страниц.
4. Укажите почту, Telegram, график, ФИО и ИНН в настройках темы. Проверьте
   отправку почты. Регистрация использует настройку «Членство» WordPress.
5. Перед публикацией заполните поля в политике и оферте, подтвердите цены,
   совместимость и характеристики. Синяя обложка Ozon происходит из референса
   WooDev: https://woodev.ru/downloads/ozon-delivery-woocommerce

Макет
Для ширины 1440 px основой служат размеры слоёв Figma Plugins-store V3.
Тексты, кнопки и формы представлены HTML, а изображения сохранены как ресурсы.
На телефоне колонки перестраиваются. Мобильный вариант выведен из desktop-макета.
Шрифт Geologica включён вместе с лицензией SIL OFL в assets/fonts.

Работа с темой
- Файлы views/*.php содержат разметку экранов по Figma. Оформление в
  assets/theme.css и assets/geometry.css. Сценарии фильтров и окон в assets/theme.js.
- Обычные записи и страницы WordPress выводятся через стандартный цикл.
  Подборка блога и каталог из макета служат стартовым содержимым темы.
- Заявки идут на настроенный адрес или на email администратора. Форма услуг
  принимает DOC, DOCX, PDF и TXT до 5 МБ. Отправка зависит от почты на хостинге.
- Для входа и восстановления пароля используются механизмы WordPress.
- MVP кабинета показывает одну назначенную администратором лицензию и архив
  на пользователя. Заполните данные в профиле пользователя, раздел
  «Лицензия Plugins-store». URL архива должен быть выдан вашей системой хранения.
- Обращения сохраняются как приватные записи в разделе «Обращения Plugins-store».
  В кабинете отображается последнее обращение. Ответ можно указать в
  произвольном поле psv3_reply административной записи.
- Каталог принимает заявки. Встроенной корзины или онлайн-оплаты нет.
